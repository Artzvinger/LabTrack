# LabTrack

Fullstack-приложение для учёта лабораторных образцов.

LabTrack позволяет просматривать образцы, отслеживать их статус и управлять доступом к данным в зависимости от роли пользователя и его лаборатории.

## Возможности

- Авторизация и управление пользовательской сессией
- Просмотр списка лабораторных образцов
- Фильтрация по статусу и сортировка по датам
- Пагинация и просмотр общего количества записей
- Просмотр подробной информации об образце
- Разграничение доступа между лабораториями
- Валидация данных на frontend и backend
- API-тесты для проверки авторизации и прав доступа

## Технологии

**Frontend:** React, TypeScript, Vite, React Router, React Hook Form, Zod

**Backend:** Node.js, Express, TypeScript, Zod

**Database:** PostgreSQL, Drizzle ORM

**Testing:** Vitest, Supertest

**Infrastructure:** Docker, Docker Compose

## Запуск

Для запуска необходимы Docker и Docker Compose.

```bash
docker compose up -d --build
```

После запуска приложение доступно по адресам:

- Frontend: http://localhost:5173
- Backend: http://localhost:3000

Миграции базы данных и заполнение тестовыми данными выполняются отдельно, если они ещё не были применены.

Остановка приложения:

```bash
docker compose down
```

## Архитектура

Frontend разделён на страницы, UI-компоненты, API-запросы, схемы валидации и TypeScript-типы.

Backend разделён на маршруты, middleware, работу с базой данных, схемы валидации и тесты.

Проверка авторизации и прав доступа выполняется на backend. Администратор имеет доступ ко всем образцам, а пользователь лаборатории — только к образцам своей лаборатории.

Для авторизации используются серверные сессии, хранящиеся в PostgreSQL. Пароли хранятся в виде bcrypt-хешей.

## Тестирование

```bash
cd server
npm test
```

Тесты проверяют авторизацию, получение списка образцов, валидацию идентификатора и разграничение доступа между лабораториями.
